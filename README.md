# QOZĞAL — Путь Батыра 🏹

**AI-тренер в браузере, которым управляешь телом.** Встань перед веб-камерой: приложение считает повторения,
**замечает ошибки техники и подсказывает, как их исправить** — текстом, голосом, подсветкой сустава и стрелкой.

## Быстрый старт

```bash
npm install      # также скачивает модели MediaPipe в public/ (self-host, без CDN)
npm run dev      # http://localhost:5173 — камера работает на localhost без HTTPS
```

Требования: Node.js ≥ 20, браузер Chrome / Edge / Safari / Firefox, веб-камера.
Для проверки с телефона нужен HTTPS — используйте деплой на Vercel.

**Деплой на Vercel:** Import Project → этот репозиторий → всё определяется автоматически (`vercel.json`). Модели MediaPipe скачиваются при `npm ci` (postinstall) и отдаются с нашего домена.

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер |
| `npm run build` | продакшн-сборка в `dist/` |
| `npm test` | юнит-тесты (Vitest) |
| `npm run lint` / `npm run typecheck` | ESLint / TypeScript |
| `?dev=1` в URL | debug-HUD: FPS, углы суставов, признаки — для подбора порогов |

## Как это работает

```
Камера → MediaPipe PoseLandmarker (WASM + GPU) → One Euro сглаживание → признаки (3D-углы, пропорции)
      → FSM фаз упражнения → подсчёт повторений
      → правила ошибок (по фазам, с persistence) → арбитр подсказок → текст + голос + подсветка + стрелки
```

- `src/core` — камера, MediaPipe, фильтры, геометрия, извлечение признаков (`FrameFeatures`)
- `src/engine` — `ExerciseRunner`, DSL правил ошибок, `RuleTracker`, `FeedbackArbiter`, setup-правила
- `src/exercises` — описания упражнений: фазы, метрики повторения, правила ошибок, пороги
- `src/ui` — экраны, оверлей (скелет, стрелки), HUD
- `src/audio` — синтезированные звуки и голосовые подсказки (Web Speech API)

## Режим «Ошибка» (твист)

Каждое упражнение описано декларативно: **фазы движения** + **правила ошибок**. Правило — это условие над
3D-углами суставов и нормированными расстояниями, привязанное к фазе, с текстом «что не так» и «как исправить»,
списком суставов для подсветки и стрелкой направления исправления.

| Уровень | Пример |
|---|---|
| Постановка в кадре | «Не видно ступней — отойди на 1–2 шага назад», «Ты стоишь боком — повернись лицом к камере», «В кадре несколько человек» |
| Безопасность | «Колени заваливаются внутрь — разводи колени наружу, по линии носков» |
| Засчитанность | «Не засчитано: неглубокий присед — присядь глубже, бедро до параллели с полом» |
| Техника | «Корпус слишком наклонён — держи грудь выше и садись назад», «Ты садишься на одну ногу» |
| Темп | «Слишком быстро — опускайся на 2 счёта» |

Против ложных срабатываний: ошибка активируется только если держится ≥200–300 мс, снимается с гистерезисом;
одновременно показывается **одна** главная подсказка по приоритету; голос не повторяет одно и то же чаще раза в 5 с;
когда пользователь исправился — «Отлично, так держать!». Пока есть проблема с кадром, счёт на паузе.

## Распознаваемые движения

| Движение | Действие | Статус |
|---|---|---|
| Приседание | +1 повторение, проверка глубины/колен/корпуса/симметрии/темпа | ✅ |
| Jumping Jack | +1 повторение | 🚧 |
| Выпад | +1 на каждую ногу | 🚧 |
| Жим над головой («Поднять щит») | +1 повторение | 🚧 |
| Наклоны в сторону («Уклон от стрелы») | +1 влево/вправо | 🚧 |
| Жесты UI: рука-курсор, обе руки вверх, руки крестом, свайп | навигация без мыши | 🚧 |

## Приватность

Видео **не покидает устройство**: распознавание выполняется локально в браузере, на сервер ничего не отправляется.
