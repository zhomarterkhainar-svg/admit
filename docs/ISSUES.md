# Задачи и статус

> Обновлено: 28.09, вечер. «Готово» = сделано и покрыто тестами / проверено в браузере (headless). **[камера]** = нужны люди с камерой.

## Готово

**Ядро**
- Каркас Vite + React 19 + TS strict, ESLint, Prettier, Vitest, CI (lint/typecheck/test/build), `vercel.json`
- Self-host MediaPipe wasm + модели (`scripts/fetch-models.mjs`, postinstall), fallback на CDN
- Камера с понятными ошибками; PoseTracker (GPU→CPU, full на десктопе / lite на мобильных, до 2 людей)
- PoseLoop (requestVideoFrameCallback, One Euro), `PoseSource`, общий для камеры и демо
- `FrameFeatures`: 3D-углы, наклон/питч/боковой наклон, стойка, valgus, kneeDrop/kneeInward, подъём рук, видимость

**Режим «ошибка»**
- DSL `FrameRule`/`RepRule`, `RuleTracker` (persistence/hysteresis), `FeedbackArbiter` (приоритеты, кулдаун TTS, «исправил»)
- Setup-правила: нет человека, ступни, далеко, край, руки, боком, несколько людей (счёт на паузе)
- 5 упражнений, 22 правила техники с конкретными подсказками, стрелками и подсветкой
- Призрак правильной позы поверх пользователя + мини-тренер в углу

**Продукт**
- Жесты: курсор-рука (reach box) + dwell, руки вверх, руки крестом, свайп
- Экраны: приветствие → калибровка (+ пропуск) → меню → программа (интро с призраком и отсчётом → упражнение → пауза) → итоги → рекорды
- Батыр Челлендж (60 с, окно реакции, комбо ×4, жизни, подсказки ошибок)
- XP, ранги, история, рекорды, имена батыров без клавиатуры
- Голос (ru/kk/en), синтезированные звуки-домбра, частицы, конфетти
- Полные словари ru / kk / en
- Демо без камеры: виртуальный батыр с ошибками; e2e-прогон в Playwright без ошибок консоли
- Мобильная портретная раскладка (проверено на вьюпорте iPhone 13)
- Dev-инструменты `?dev=1`: признаки, живой раннер правил, kNN, запись движений → `tests/fixtures`
- «Слишком темно» (яркость кадра), авто full→lite при низком FPS, телеметрия MediaPipe закрыта CSP
- kNN-классификатор поз («другое упражнение»), `npm run train`
- Голос: при kk без казахского голоса озвучка по-русски
- Скриншоты в README
- Персональная база (калибровка / авто), правила только по видимым суставам, фильтр шумовых повторов
- Аугментация модели (поворот, наклон камеры, зеркало, шум глубины) + тест устойчивости
- Свободная тренировка: AI распознаёт упражнение (kNN) и считает каждое
- Геймификация: 11 ачивок, серия дней, квест дня, «N чисто подряд», голосовой счёт
- Лидерборд: сегодня/неделя/всё время, мировой через Supabase (docs/LEADERBOARD.md)
- DTW-плавность повторов
- Новый репозиторий zhomarterkhainar-svg/admit, ветка main
