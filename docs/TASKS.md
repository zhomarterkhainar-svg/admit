## Задача 4. Ритм-режим «Қара жорға» (главная фича, делать качественно) — ~8+ ч

Игрок танцует под домбру: движения нужно сделать **точно в долю**, как в Just Dance / osu!.

### 4.1 Движения — `src/game/dance/moves.ts`

У каждого движения есть:
- `id`, ключ перевода;
- эталонная поза `PoseEdit` (для иконки и демо-танцора);
- `match(f: FrameFeatures, frame: PoseFrame): boolean`.

| id | Название | Условие (признаки из `extract.ts`) | Эталон |
|---|---|---|---|
| `reins` | Тізгін (поводья, фирменное движение жорги) | запястья на уровне груди `wristLift ∈ [-0.8,-0.1]`, локти согнуты `elbowAngle ∈ [50,130]`, руки не сведены | локти вперёд, кисти перед грудью |
| `up` | Қол жоғары | `wristAboveHead.l && .r`, локти > 130° | `pressTop()` |
| `wings` | Қанат | `shoulderAngle ∈ [65,120]` у обеих рук, локти > 140° | руки в стороны |
| `leanL` / `leanR` | Солға / Оңға | `torsoSideLean < -12` / `> 12` | `sideBend('l'/'r')` |
| `clap` | Шапалақ | расстояние между запястьями < 0.6 ширины плеч, на уровне груди или лица | кисти вместе |
| `kneeL` / `kneeR` | Тізе | `kneeDrop.l < 0.45` и `kneeDrop.r > 0.6` (и наоборот) | бедро вперёд-вверх |
| `squat` | Отыр | средний угол колена < 125° | `squatDown()` |

Тест: каждый эталон проходит **только свой** матчер (как `errorExamples.test.ts`).

### 4.2 Музыка — `src/audio/dombra.ts`

- **Общий контекст.** `AudioContext` берём из `src/audio/sfx.ts`: экспортировать геттер. Там уже есть Karplus–Strong `pluck()`.
- **Синтез.** Буферы нот кешировать по частоте.
  - Домбра: 2 струны D3 / G3, мелодия на верхней, бурдон на нижней.
  - Удар «вниз» акцентный, «вверх» тише, разброс струн 12–18 мс.
- **Ритм «жорға» (иноходь).** На каждую долю: удар в 0 и лёгкий удар в 2/3 доли («ДАМ-да ДАМ-да»).
  - Добыл (kick): синус 120→50 Гц с затуханием.
  - Шумовой шейкер на слабые доли.
- **Темп и форма.** 120 BPM. Intro 8 долей → A 32 → B 32 → A′ 32 → B′ 32 → outro 8 (≈ 72 с).
- **Мелодии** (MIDI, G-миксолидийский):
  - A: `59 57 55 55 57 59 62 62 64 62 59 57 59 57 55 55`;
  - B: `67 67 69 67 64 62 64 67 71 69 67 64 62 64 62 59`.
- **Планировщик.** Lookahead-планировщик (ставить ноты на ~150 мс вперёд по `setInterval(25)`).
  API: `start()`, `pause()` (`ctx.suspend`), `resume()`, `stop()`, `songMsAt(perfMs)`, `durationMs`.
- **Синхрон — самое важное.** Позиция песни по времени `performance.now()`:
  - `ctx.getOutputTimestamp()` → `songSec = ts.contextTime + (perf − ts.performanceTime)/1000 − T0`
    (это учитывает задержку вывода звука);
  - фолбэк: `ctx.currentTime − T0 − ctx.outputLatency`.
- **Музыка реагирует на игру.** При комбо ≥ 16 включать второй слой домбры (гармония на терцию выше)
  и золотую подсветку «ЖОРҒА!».

### 4.3 Хореография и судья — `src/game/dance/chart.ts`, `judge.ts`

- **Карта.** Движение каждые 2 доли (уровень «Орта») или каждые 4 («Жеңіл»), по секциям песни:
  - A: `reins leanL reins leanR reins leanL reins leanR wings up wings up clap clap reins reins`;
  - B: `up wings up wings kneeL kneeR kneeL kneeR clap up clap up squat up squat up`.
- **Судья.**
  - Для каждой ноты окно `[t − 400, t + 450]`.
  - Время позы: `tick.t − LATENCY_MS`, где `LATENCY_MS` ≈ 120 для камеры и 0 для демо.
  - Минимальное |смещение| кадров, где матчер true: ≤ 130 мс — «Керемет» (perfect), ≤ 300 мс — «Жақсы» (good),
    иначе промах. Perfect засчитывать сразу, остальное — по закрытию окна.
  - Удержание позы через долю автоматически даёт perfect.
- **Очки.**
  - Perfect 100, good 50, множитель `min(4, 1 + floor(combo/8))`.
  - Точность `(P + 0.5·G)/N`, оценка: S ≥ 95%, A ≥ 85%, B ≥ 70%, C ≥ 50%, иначе D.
- **Тесты.**
  - Синтетическая последовательность поз «в долю» → все perfect.
  - Сдвиг на 250 мс → good.
  - Не то движение → промах.

### 4.4 Экран — `src/ui/screens/Dance.tsx` (+ экран `'dance'`)

- **Выбор.**
  - Экран: заголовок «Қара жорға», Барыс: «Билейміз! Қозғалысты дәл ырғаққа жаса».
  - Кнопки «Жеңіл / Орта», легенда движений (иконки), «Руки вверх — старт».
- **Отсчёт.** Музыка начинается, 8 долей вступления, 4-3-2-1 на долях 4–7.
- **Игра** (фон — камера со скелетом).
  - Сверху: большая карточка текущего движения с иконкой и названием + сжимающееся кольцо, которое
    закрывается ровно в долю. Рядом счёт, комбо, точность, тонкая полоса прогресса песни.
  - Снизу «дорожка»: иконки следующих движений едут справа налево к кругу попадания, линии долей и тактов.
    Рисовать на canvas в `requestAnimationFrame` по `songMsAt(performance.now())`, **не** по тикам позы,
    чтобы было 60 fps и синхронно со звуком.
  - Иконки движений: заранее отрисовать каждую эталонную позу в offscreen-canvas
    (`drawSkeleton` + `fitFrame` из `GhostPreview.tsx`) и потом `drawImage`.
  - Всплывашки «КЕРЕМЕТ! / ЖАҚСЫ / ӨТКІЗДІ», пульс круга попадания на каждую долю.
  - Барыс в углу качается в темп (`animation-duration` = 2 доли).
- **Пауза.** Руки крестом → `ctx.suspend()` + `PauseModal`, руки вверх → продолжить.
  Движение `up` во время игры жестом «старт» не считать.
- **Итоги.** Большая буква оценки, очки, точность, P/G/M, лучшее комбо, XP, «Новый рекорд», кнопки «Ещё / Лидерборд / Меню».
- **Демо без камеры.** `demo.followTimeline(perf => позаДляВремени(songMsAt(perf)))`:
  - перетекание к позе следующей ноты за 300 мс до доли, удержание после;
  - иногда нарочно опаздывать (каждая 11-я нота +350 мс) и ошибаться (каждая 17-я — не то движение),
    чтобы жюри видело работу судьи.
